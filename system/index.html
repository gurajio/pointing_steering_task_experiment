ポインティング習熟実験

参加者・実施条件を設定してください。

実験の設定

1条件を208試行訓練し、最後に全4条件を事後測定します。

訓練条件（1つ選択）
同じ訓練条件の参加者ごとに1から採番します。事後の順序に反映されます。

実験の流れ

  1. 表示校正・共通説明

    定規で表示の長さを測り、教示を確認します。

  2. 訓練

    選択した1条件を208試行（13移動×16周）実施します。一周後も次の円へ続けて移動します。

  3. 休憩

    条件切替時・訓練終了時に休憩します。途中でもEscキーで停止できます。

  4. 事後測定・保存

    訓練の後、4条件を26試行ずつ測定し、CSVと詳細JSONを保存します。

課題中は数値・成績を表示しません。クリックの初回成否と修正クリックを分けて記録します。

記録の再開・再保存

同じブラウザ・同じURLの保存領域から復旧します。

途中保存は復旧用です。終了時はCSVとJSONをファイルとして保管してください。

A・Wの設定

訓練・事後測定に共通する4条件の寸法を編集します。

Aは次に選択するターゲットまでの中心間の直線距離、Wは円形ターゲットの直径です。単位はmmです。

条件A：中心間距離 (mm)W：円の直径 (mm)ID (bit)

ID = log₂(A/W + 1)。円周上の13ターゲットが接触・重複しない値を設定してください。画面内に収まるかは、この後の表示校正で確認します。

表示サイズの校正

実験者が定規で確認してください。刺激は自動縮小しません。
