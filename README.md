# ポインティング習熟実験

2026-09-24実装。本実験では割り当てた1条件を208試行訓練した後、全4条件の事後テスト104試行（合計312試行）を行うローカルWebアプリです。予備実験では訓練条件を複数選択できます。追加の操作確認試行はありません。

## フォルダ構成

```text
pointing_steering_task_experiment/

│   ├── index.html                  実験の入口
│   ├── tests/                      実験ロジックのテスト

├── analysis/                       結果分析
│   ├── analysis_horizontal_steering_experiment.py
│   ├── inputCSV/                   解析する試行CSV

└── research/                       文献・A/W検討資料・文献データの再計算
```

以下のコマンドは、このREADMEがあるプロジェクト直下で実行します。解析スクリプトのファイル名は指定名を維持していますが、処理内容はポインティングCSV用です。

## 起動

このフォルダで次のコマンドを実行します。既に8766番のサーバーが動いていれば再起動は不要です。

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

[実験システムを開く](http://127.0.0.1:8766/system/)。フォルダ整理後はURLの末尾に`/system/`を付けます。HTMLファイルの直接起動（file://）には対応しません。Fullscreen API・IndexedDB・Web Locksを利用できるデスクトップブラウザで実行してください。実験システムには追加パッケージのインストールは不要です。

記録の復旧には**同じブラウザ・プロファイル・URL（ホストとポート）**を使います。127.0.0.1とlocalhostは保存領域が異なります。

## 実施手順

1. 必要に応じて右上の「A・Wの設定」で寸法を編集し、適用します。参加者IDと訓練条件、割当番号を入力します。本実験では1条件を選び、同じ訓練条件の参加者ごとに番号を1から採番してください。予備実験ではチェックボックスで1〜4条件を選べます。
2. 全画面にし、400 CSS pxの横線を定規で実測します。値を入力し、横・縦の100 mmを再確認して校正を確定します。解像度、表示倍率、マウス設定も記録できます。不明な値は空欄のまま保存します。
3. 共通教示を読み、訓練を開始します。上端の青い円の開始クリックは試行数に含みません。
4. 選択した各条件を208試行（13移動×16周）訓練した後、事後テストへ進みます。予備実験で複数選択した訓練条件の順序も割当番号で決まります。事後は全4条件について13移動のラウンドを2回、各条件計26試行です。事後の順序は割当番号で決まります。開始画面に実際の順序と合計試行数を表示します。
5. 終了時にCSVのダウンロードを開始します。詳細JSONも保存し、保存先を確認してから次の参加者へ進みます。

同一条件の周回は停止せず連続します。始点へ戻った成功クリックを次の移動の開始時刻に使い、同じ円の再クリックは要求しません。条件変更時・訓練終了時は休憩画面を表示します。Esc、画面切替、全画面解除、表示サイズ変更で停止します。表示環境が変わった場合と保存記録を開き直した場合は、再校正が必要です。

本実験は合計312試行です。予備実験は「選択条件数×208＋104」試行で、1〜4条件の場合は312・520・728・936試行です。課題形状、A/W、計時、保存方法は共通で、`experimentMode`とファイル名で区別します。

## 条件の初期値と編集

| 条件 | A：中心間距離 (mm) | W：円の直径 (mm) | ID (bit) |
|---|---:|---:|---:|
| C1 短距離・大ターゲット | 90 | 20 | 2.459 |
| C2 短距離・小ターゲット | 90 | 10 | 3.322 |
| C3 長距離・大ターゲット | 180 | 20 | 3.322 |
| C4 長距離・小ターゲット | 180 | 10 | 4.248 |

13個の円を円周上に配置し、ほぼ反対側へ順次移動する多方向タッピング課題です。公称IDは`log2(A/W + 1)`。Aは次のターゲットとの中心間の直線距離で、配置円の直径は`A / cos(π/26)`です。正式なサイズは実機校正値でmmからCSS pxへ換算し、画面に合わせた自動縮小はしません。

「A・Wの設定」で全4条件をmm単位で編集できます。ID・配置寸法を再計算し、ゼロ・負数・非数値や、円同士が接触・重複する設定は適用しません。「変更せず戻る」は編集を破棄し、「初期値に戻す」は初期値を入力欄へ戻します。適用後は訓練と事後の両方でその寸法を使います。開始時の設定をセッションに固定するため、以前の記録を開いても新しい設定に置き換わりません。

本実験の訓練条件は1つです。予備実験では複数選択でき、割当番号に対応する4条件の順序表から選択条件だけを取り出して訓練順序を決めます。事後も同じ順序表を利用し、開始画面と保存データで確認できます。複数条件を選択した予備実験から本実験へ切り替えた場合は、訓練条件を改めて1つ選びます。

1試行は1移動です。最初の上端クリックは位置合わせで数えず、上端へ戻る移動まで含めて13試行とします。その直前で終了すると12移動になるため、訓練は始点への復帰を含む16周です。各方向を16回実施します。事後の各26試行は2つの完全な系列です。

## 計時・記録

- 主指標のMTは、直前の成功した左ボタン押下から、現在ターゲットに対する初回押下まで。`performance.now()`で計時します。
- 初回ミスも1試行として記録します。同じターゲットを押し直し、修正クリックの回数・成功までの時間を別に保存します。初回の成否・座標・MTは上書きしません。
- 初回前の中断は非カウントのattemptとして残し、同じ論理試行を再実施します。初回ミス後の中断では確定したエラーを保持し、再開時の位置合わせ後に次の論理試行へ進みます。
- CSVは1行1attempt。通常の解析では`countedAsTrial=true`を使い、`phase`で訓練と事後を区別します。`trainingConditions`は訓練条件の配列（CSVではJSON文字列、訓練順）、`conditionId`はその試行の条件です。1条件の場合は`trainingCondition`にも保存し、複数条件の場合はこの列を空欄にします。
- JSONには全試行、クリック、軌跡、イベント、表示校正履歴、時計の基準、実行時設定を保存します。軌跡の`t`はハンドラの時刻、元イベントの時刻は`rawEventTimestamp`です。coalescedイベントの出自も区別します。
- IndexedDBへ非同期に途中保存し、条件・フェーズの切替前に保存完了を待ちます。同条件の周回境界では計時を続け、保存待ちを挟みません。同じセッションへの同時書込みはWeb Locksで拒否します。強制終了直前の未コミット分までの保存は保証しません。
- 保存容量不足等で失敗した場合は停止し、メモリ上のCSV/JSON出力と保存の再試行を提供します。外部サーバーへの参加者データ送信はありません。

## 結果分析

実験終了時に保存した試行CSV（末尾が`_trials.csv`）を`analysis/inputCSV/`に入れます。フォルダ内の全CSVを読み、`experimentMode`では絞り込みません。今回の入力は参加者001の訓練208試行と事後104試行です。

この環境ではMatplotlibを利用できる既存のPython 3.12で実行します。

```sh
/usr/local/bin/python3.12 analysis/analysis_horizontal_steering_experiment.py
```

同一IDのC2・C3について習熟過程を比較する場合は、次も実行します。13試行を1周として、周平均MTの学習曲線、初期4周と終盤4周の変化、初回ミス率を出力します。

```sh
python analysis/analyze_same_id_learning.py
```

解析にはMatplotlibを使用します。入力・出力先はスクリプトの場所を基準に決まるため、別の作業ディレクトリから実行しても同じフォルダを使います。必要な場合は`--input-dir`と`--output-dir`で変更できます。

- 対象は`countedAsTrial=true`の行。訓練（`training`）と事後（`post`）を分け、事後はC1〜C4別に集計します。
- MTは`mtFirstMs`で、初回ミスも含みます。外れ値の自動除外は行いません。
- エラー率は`firstHit=false`の試行数÷対象試行数です。修正クリックは分母に加えません。
- 推移は参加者・セッション・条件別の`trialInCondition`を使い、1〜10、11〜20…の重複しない区間で集計します。末尾の訓練8試行・事後6試行も実際の試行数で平均と率を計算します。
- 複数CSVの全体平均・条件別平均は試行数で重み付けされます。推移の線は参加者・セッションごとに分け、同じ試行の重複入力はエラーにします。

平均MTとエラー率は標準出力に表示し、以下を`analysis/output/`へ保存します。同名の出力は再実行時に更新します。

| 出力 | 内容 |
|---|---|
| `summary.csv` | フェーズ・条件別の試行数、エラー数、平均MT、エラー率 |
| `10trial_summary.csv` | 各区間の開始・終了試行、試行数、平均MT、エラー率 |
| `training_mt_histogram.png` / `post_mt_histogram.png` | MTの分布（50 ms幅） |
| `training_mt_10trial_trend.png` / `post_mt_10trial_trend.png` | 10試行平均MTの推移 |
| `training_error_10trial_trend.png` / `post_error_10trial_trend.png` | 10試行ごとのエラー率の推移 |
| `training_error_10trial_histogram.png` / `post_error_10trial_histogram.png` | 区間別エラー率の分布（10パーセントポイント幅） |
| `same_id_13trial_summary.csv` | C2・C3の13試行（1周）ごとのMT・初回ミス率 |
| `same_id_learning_summary.csv` / `same_id_learning_comparison.csv` | 条件別の初期・終盤変化と学習曲線の傾き、その条件差 |
| `same_id_learning_curve.png` / `same_id_learning_report.md` | 同一ID条件の習熟曲線と解釈・制約 |

事後テストの画像はC1〜C4を分けた4パネルです。エラー率のヒストグラムは区間数を示し、末尾の短い区間も1件として数えます。
